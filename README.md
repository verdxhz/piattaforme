# 📌 Gioia

Sviluppo fullstack di un'ecommerce per la vendita di gioielli (simulato).

---

## 🚀 Tecnologie Utilizzate
- Flutter
- Java
- Springboot
- Postgress
- Keycloak

---

## ✨ Funzionalità Principali
- Log in e registrazione
- Ricercaddei prodotti
- Aggiunta/rimozione dal carrello 
- Acquisto 

---
## 📚 Scopo

Progetto universitario per sviluppo web
